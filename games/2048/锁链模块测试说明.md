| 14 | 不对齐滑动 - 其他数字合并 | 旁边数字滑向chain | 可以与chain合并 |

| 16 | 不对齐移动 - 位置更新 | 垂直连接水平滑动后 | chainPair位置正确更新 |

## 测试脚本结构说明

### 辅助函数
- `createEmptyGame()`: 创建空白游戏，清空棋盘
- `setupBoundChain(game, chainPos, chainValue, targetPos, targetValue, remainingMoves)`: 快速设置绑定的锁链对
- `printBoard(game)`: 打印当前棋盘状态
- `runTest(testName, testFn)`: 运行单个测试，捕获异常
- `assert(condition, message)`: 断言函数，失败抛出异常

### 添加新测试
在测试脚本末尾（测试汇总之前）添加：

```javascript
runTest('场景X: 你的测试名称', () => {
  const game = createEmptyGame();
  
  // 设置测试场景
  setupBoundChain(game, [1, 2], 4, [1, 3], 2);
  
  console.log('  初始状态:');
  printBoard(game);
  
  // 执行操作
  game.move('left');
  
  console.log('  滑动后:');
  printBoard(game);
  
  // 验证结果
  assert(game.chainPair !== null, '锁链应该保持连接');
  // 更多断言...
});
```

## 关键验证点

### 锁链状态检查
```javascript
// 检查是否绑定
assert(game.chainPair !== null, '应该绑定');
assert(game.chainPair === null, '应该解除');

// 检查chain位置
assert(game.chainPair.chainPos[0] === row && game.chainPair.chainPos[1] === col, 
       `chain应该在 (${row},${col})`);

// 检查倒计时
assert(game.chainPair.remainingMoves === expected, '倒计时不符');
```

### 单元格类型检查
```javascript
const cell = game.board.getCell(r, c);

// 检查是否是chain
assert(cell.isChain(), '应该是chain类型');
assert(!cell.isChain(), '不应该是chain类型');

// 检查值
assert(cell.value === expectedValue, '值不正确');

// 检查是否是冰冻
assert(cell.isFrozenNumber(), '应该是冰冻数字');
```

### 相邻性检查
```javascript
const adjacent = Math.abs(pos1[0] - pos2[0]) + Math.abs(pos1[1] - pos2[1]) === 1;
assert(adjacent, '两个数字应该相邻');
```

## 常见问题

### 1. 测试脚本无法运行（沙箱限制）
如果在某些受限环境中无法直接运行 node，请：
- 使用浏览器控制台运行
- 或复制测试逻辑到浏览器中执行

### 2. 测试失败但手动测试正常
可能的原因：
- 测试场景设置与实际游戏状态有差异
- 检查 `createEmptyGame()` 是否正确初始化了所有必要的状态
- 手动打印关键变量进行调试

### 3. 新增测试不生效
确保：
- 测试代码在测试汇总（`console.log('\n═══════════════════════════'`）之前
- 文件名正确引用
- 没有语法错误

## 扩展测试建议

可以考虑添加的测试场景：

1. **撤销操作**：测试锁链状态在撤销后是否正确恢复
2. **洗牌功能**：测试洗牌后锁链对的位置变化
3. **传送阵交互**：测试锁链对经过传送阵的行为
4. **多个特殊模块共存**：木块、冰块、传送阵、锁链同时存在的情况
5. **边界情况**：锁链对在棋盘角落的移动
6. **性能测试**：大量操作后锁链状态是否一致
