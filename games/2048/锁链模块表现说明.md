# 锁链数字模块 — 前端表现说明

## 一、锁链的视觉表现

### 1.1 未绑定的锁链方块
- 数字方块的**右上角**有一个**小锁链图标** `⛓️`
- 方块边框有**黄色高亮**
- 此时**没有倒计时数字**（绑定后才会出现）
- 同一时间棋盘上**最多有 1 个**未绑定的锁链

### 1.2 绑定后的两个数字
- 两个数字都有**黄色高亮边框**
- 两个数字的**左下角**都显示**同一个倒计时数字**
- **两个数字的右上角都有锁链图标** `⛓️`，表示它们被连接在一起
- 两个数字视觉上完全一致，都表示"被锁链锁住"

### 1.3 倒计时显示规则
- 倒计时初始值 = 5
- UI 显示的数字 = `Math.max(1, 内部剩余步数)`
- 对应关系：
  - 内部剩余 5 步 → UI 显示 `5`
  - 内部剩余 4 步 → UI 显示 `4`
  - 内部剩余 3 步 → UI 显示 `3`
  - 内部剩余 2 步 → UI 显示 `2`
  - 内部剩余 1 步 → UI 显示 `1`
  - 内部剩余 0 步 → **锁链解除，UI 不再显示倒计时**
  - （内部用 `Math.max(1, remainingMoves)` 确保不显示 0 或负数）

---

## 二、锁链的生命周期

### 2.1 生成
- 棋盘上随机生成一个带锁链的数字方块
- 同一时间棋盘上**最多有 1 个**未绑定的锁链
- 锁链解除后有**5 步冷却时间**，冷却期间不会生成新的锁链

### 2.2 绑定
- 带锁链的方块滑动后，如果**旁边有相邻的数字**（包括冰冻数字），自动绑定
- 绑定后两个数字成为一个整体

### 2.3 移动
- 绑定后的两个数字**同步移动**

### 2.4 解除
- 倒计时归零（内部剩余步数 ≤ 0）
- 或**锁链找不到了**（防御性检查，正常情况不会发生）
- 或**目标找不到了**（合并/传送/洗牌后位置变化太大）
- 或**滑动后两个数字不再相邻**（传送阵、洗牌等特殊操作后可能发生，正常滑动不会）
- 解除后两个数字都变成普通数字，锁链符号消失

---

## 术语定义

| 术语 | 定义 |
|------|------|
| **锁链对** | 绑定后的两个数字，包含 chain（带锁链图标的数字）和 target（被绑定的普通数字） |
| **对齐滑动** | 滑动方向与锁链对的连线方向一致。即：水平相邻（同一行）+ 左右滑动，或垂直相邻（同一列）+ 上下滑动 |
| **不对齐滑动** | 滑动方向与锁链对的连线方向垂直。即：水平相邻（同一行）+ 上下滑动，或垂直相邻（同一列）+ 左右滑动 |
| **相对位置** | 锁链对两个成员的位置差。如 chain 在 (r,c)，target 在 (r,c+1)，则相对位置为 (0, +1)。保持相对位置意味着移动后 target 始终在 chain 的右边一列 |
| **同步阻挡** | 锁链对作为整体，只要有一个成员被障碍物挡住，两个都不能移动 |

## 三、不同场景下的表现

### 场景 1：未绑定的锁链

| 操作 | 表现 |
|------|------|
| 滑动 | 锁链可以自由移动，和普通数字一样 |
| 合并 | **不能参与任何合并**（即使旁边有相同数字） |
| 绑定 | 滑动后如果旁边有数字，自动绑定 |

**示例**：
```
初始：[4(锁链), _, 2, 2]
向左滑动：[4(锁链), 4, _, _]
→ 正常的 2 和 2 合并成 4，但锁链数字在连接之前不参与合并，还是 4
```

---

### 场景 2：已绑定的锁链（对齐滑动）

锁链和目标**在同一行左右相邻**，玩家**左右滑动**。
（绑定后两个数字都有锁链图标，视觉上完全相同）

| 操作 | 表现 |
|------|------|
| 滑动 | 两个数字**作为整体**一起移动 |
| 前方有障碍物 | **两个都不动**（一个被挡住，另一个也不能动） |
| 其中一个与其他相同数字 | **可以合并**，合并后锁链转移到新位置，倒计时额外 -1 |
| 两个之间 | **不能互相合并**（即使值相同） |

**示例 1：正常移动**
```
初始：[_, _, 4(锁链), 4(锁链)]
       （两个都有锁链图标，视觉上相同）
向左滑动：[4(锁链), 4(锁链), _, _]
→ 两个一起移动到最左边
```

**示例 2：前方被挡住**
```
初始：[🪵, 4(锁链), 4(锁链), _]
向左滑动：[🪵, 4(锁链), 4(锁链), _]
→ 前方有木块挡住，两个都不动
```

**示例 3：左边合并**
```
初始：[4, 4(锁链), 4(锁链), _]
向左滑动：[8(锁链), 4(锁链), _, _]
→ 正常的 4 和第一个 4(锁链) 合并成 8(锁链)
→ 倒计时：5 - 1(滑动) - 1(合并) = 3
```

**示例 4：右边合并**
```
初始：[4(锁链), 4(锁链), 4, _]
向左滑动：[4(锁链), 8(锁链), _, _]
→ 第二个 4(锁链) 和正常的 4 合并成 8(锁链)
→ 倒计时：5 - 1(滑动) - 1(合并) = 3
```

**示例 5：不能互相合并**
```
初始：[_, _, 4(锁链), 4(锁链)]
向左滑动：[4(锁链), 4(锁链), _, _]
→ 即使都是 4，也不能互相合并
```

---

### 场景 3：已绑定的锁链（不对齐滑动）

锁链和目标**上下相邻**（同一列不同行），玩家**左右滑动**。

| 操作 | 表现 |
|------|------|
| 滑动 | **两个都不动**！（滑动方向不在它们的连线上） |
| 其他数字 | 可以正常移动、合并，不受影响 |

**示例**：
```
初始（行0）：[ _, 4(锁链), _, _ ]
初始（行1）：[ _, 4(锁链), _, _ ]
初始（行2）：[ 2, 2, _, _ ]
        （两个都有锁链图标，视觉上相同）

向左滑动：
行0：[ _, 4(锁链), _, _ ]  → 不动
行1：[ _, 4(锁链), _, _ ]  → 不动
行2：[ 4, _, _, _ ]        → 正常合并
→ 锁链对因为不在同一行，所以不动
```

---

### 场景 4：倒计时

| 事件 | 倒计时变化 |
|------|----------|
| 每次滑动 | -1 |
| 其中一个合并 | 额外 -1 |
| 两个都合并 | 额外 -2 |

**示例**：
```
绑定后倒计时 = 5
滑动1（不合并）→ 5 - 1 = 4
滑动2（其中一个合并）→ 4 - 1 - 1 = 2
滑动3（不合并）→ 2 - 1 = 1
滑动4（另一个合并）→ 1 - 1 - 1 = -1 → 解除锁链！
```

---

### 场景 5：撤销

| 操作 | 表现 |
|------|------|
| 撤销滑动 | 锁链状态完全恢复，包括倒计时数字 |
| 倒计时 | 撤销时倒计时**增加**（和移动相反） |
| 锁链符号 | 撤销时锁链符号恢复 |

**示例**：
```
滑动前倒计时 = 4
滑动后倒计时 = 3
撤销后倒计时 = 4  ✓ （恢复到滑动前）
```

---

### 场景 6：与冰冻数字交互

| 情况 | 表现 |
|------|------|
| 锁链绑定冰冻数字 | ✅ 可以绑定 |
| 冰冻数字与锁链一起移动 | 冰冻数字不会因为移动而解除冰冻 |
| 其中一个是冰冻数字且合并 | 合并后变成普通数字（不是冰冻） |

**示例**：
```
初始：[4(锁链), 4(冰冻, 锁链), _]
       （两个都有锁链图标，视觉上相同）
向左滑动：[4(锁链), 4(冰冻, 锁链), _]
→ 它们已经在最左边，不动
```

---

### 场景 7：与传送阵交互

| 情况 | 表现 |
|------|------|
| 其中一个进入传送阵 | 尝试把另一个也一起传送 |
| 一起传送 | 保持相对位置不变 |
| 不能一起传送 | 尝试只传送单个数字 |

---

### 场景 8：与洗牌交互

| 操作 | 表现 |
|------|------|
| 洗牌 | 两个锁链方块的位置跟随洗牌变化 |
| 洗牌后不相邻 | 解除锁链 |
| 洗牌后找不到 | 解除锁链 |

---

## 四、解除后的表现

### 4.1 解除瞬间
- 两个数字的黄色高亮边框消失
- 锁链图标消失
- 倒计时数字消失
- 两个数字变成普通数字

### 4.2 冷却
- 解除后 5 步内不会生成新的锁链
- 冷却期间 UI 没有特殊显示（内部计数）

---

## 五、总结

| 情况 | 第一个锁链方块 | 第二个锁链方块 | 备注 |
|------|--------------|--------------|------|
| 对齐滑动 | 一起移动 | 一起移动 | 保持相对位置 |
| 不对齐滑动 | 一起移动 | 一起移动 | **保持相对位置**，和对齐行为完全一致 |
| 前方被挡 | 不动 | 不动 | 同步语义：一个被挡，另一个也不能动 |
| 其中一个合并 | 可以（停在合并位置） | 保持相对位置 | 没参与合并的那个移动到保持相对位置的地方，即使还有空位也不能继续滑动 |
| 其中一个合并 | 保持相对位置 | 可以（停在合并位置） | 没参与合并的那个移动到保持相对位置的地方 |
| 互相合并 | ❌ 不能 | ❌ 不能 | |
| 撤销 | 完全恢复 | 完全恢复 | 倒计时也恢复 |

**⚠️ 核心原则**：锁链对是一个不可分割的整体。无论对齐还是不对齐滑动，都保持相对位置不变，同步移动，同步被挡。一个合并后，另一个调整位置保持相对关系。无法保持相对位置时自动解除锁链。

（绑定后两个数字视觉上完全相同，都有锁链图标）
