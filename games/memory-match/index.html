📖 游戏说明

🎯 游戏目标：将所有卡片配对完成即可通关

🎮 操作方式：点击卡片翻开，每次可翻开两张

✅ 配对成功：两张卡片图案相同则保持翻开状态

❌ 配对失败：卡片会在1秒后自动翻回

🏆 挑战目标：用最少的步数和最短的时间完成配对

🔓 解锁关卡：通关当前关卡后自动解锁下一关

💣 炸弹机制：部分关卡中会出现💣炸弹卡片，翻开两张炸弹配对会立即失败！请谨慎避开炸弹，专注于配对普通卡片

⭐ 星级系统：根据步数获得1-3星评价：
    • ⭐⭐⭐ 3星：步数 ≤ 配对数 × 3（出色发挥）
    • ⭐⭐ 2星：步数 ≤ 配对数 × 4（表现良好）
    • ⭐ 1星：通关即可获得
    集齐一定星星可解锁隐藏关卡！

🔥 连击系统：连续配对成功可累积连击：
    • 3连击：闪烁特效 + "+1步数减免"
    • 5连击：彩色粒子 + "+2步数减免"
    • 10连击：全屏特效 + 解锁"连击大师"成就

⏱️ 限时模式：每关有时间限制，时间归零则失败！
    剩余时间按比例奖励步数减免
    完成所有限时挑战解锁"时间领主"成就
