## 一、P0 - 体验优化（近期应做）

### 1.1 响应式适配优化

**现状问题**：2×3 到 6×6 的16关布局差异极大，小屏手机上6×6关卡的卡片过小无法操作。

**方案**：
- 用 `clamp()` 函数动态计算卡片尺寸：`clamp(40px, min(120px, (100vw-40px)/cols), 120px)`
- 小屏自动缩小棋盘 padding 和 gap
- 关卡选择下拉菜单在小屏上改为单列滚动
- 模态框在小屏上占满屏幕，底部弹出
- 触摸设备增加 `touch-action: manipulation` 消除300ms延迟

### 1.2 键盘无障碍支持

**现状问题**：完全依赖鼠标/触摸点击，键盘用户无法操作。

**方案**：
- 卡片元素添加 `tabindex="0"` 和 `role="button"`
- Enter/Space 键触发翻牌
- Tab 键在卡片间移动焦点
- 添加 `aria-label` 描述卡片状态（"第3张卡片，未翻开"）
- 添加 `aria-live` 区域播报配对结果
- 添加"跳过导航"链接

### 1.3 卡片翻牌性能优化

**现状问题**：`flipCard` 中每次点击都 `querySelector` 操作 DOM，`createBoard` 用 `innerHTML` 完全重建。

**方案**：
- 预创建卡片数组引用，翻牌时直接通过 `cards[index]` 对象操作
- 使用 `DocumentFragment` 批量插入卡片 DOM
- `unflipCards` 的1000ms 延迟用 `transitionend` 事件替代 `setTimeout`，更精确

### 1.4 数据导入导出

**方案**：
- 设置面板增加"导出数据"按钮，下载 JSON 文件
- 增加"导入数据"按钮，上传并合并进度
- 用于换设备/浏览器时迁移数据

## 二、P1 - 玩法增强（中期迭代）

### 2.1 星级评分系统

**描述**：每关完成后按步数评1-3星。

**实现**：
```javascript
function calcStars(levelIndex, moves) {
    const optimalMoves = gameLevels[levelIndex].pairs * 2; // 最优步数 = 配对数×2
    if (moves <= optimalMoves) return 3;          // 无失误
    if (moves <= optimalMoves * 1.5) return 2;     // 少量失误
    return 1;                                       // 通关
}
```
- 星星显示在关卡选择按钮上
- 集齐一定星星数解锁隐藏关卡或奖励
- 新增成就"满星通关"、"三星大师"

### 2.2 特殊功能卡片

**描述**：在某些关卡中随机出现功能卡片，翻开后触发特殊效果。

| 卡片 | 概率 | 效果 |
|------|------|------|
| 🔀 洗牌 | 10% | 所有未翻开卡片随机洗牌 |
| 👁️ 窥视 | 8% | 翻开所有卡片展示1.5秒后翻回 |
| ⏰ 冻结 | 8% | 暂停计时器5秒 |
| ⭐ 双倍 | 5% | 下次配对计为2对 |
| ❓ 未知 | 7% | 随机触发以上任一效果 |

**配置化**：每个功能卡片的效果在 `config.js` 中定义，关卡配置中指定是否启用及概率。

### 2.3 连击（Combo）系统

**描述**：连续配对成功获得 combo 加成。

- 连续配对计数，每次配对失败重置
- 3连击：闪烁特效 + "+1 步数减免"
- 5连击：彩色粒子 + "+2 步数减免"
- 10连击：全屏特效 + 自动解锁"连击大师"成就
- combo 数显示在棋盘上方

### 2.4 限时挑战模式

**描述**：除常规模式外，增加限时挑战。

- 每关设定时间上限（如 60秒-180秒不等）
- 倒计时归零判定失败
- 剩余时间按比例奖励额外步数减免
- 完成所有限时挑战解锁"时间领主"成就

### 2.5 每日挑战

**描述**：每天自动生成一局固定布局的挑战。

- 使用日期字符串作为随机种子，保证同一天所有玩家面对同样的布局
- 完成后可查看当日排行榜（同一设备上的本地排行）
- 连续7天完成获得"挑战周"成就
- 棋盘种子生成算法：`seededShuffle(array, dateString)`

### 2.6 提示系统

**描述**：玩家卡住时可以获得提示。

- 每关默认3次提示机会
- 点击"提示"按钮，短暂高亮一对未配对的匹配卡片（1.5秒闪烁）
- 使用提示不计入最佳步数
- 零提示完成获得"独立思考"成就

## 五、创新玩法构想（纯本地、无需联机）

### 5.1 时间回溯机制

**核心创意**：玩家可以"撤销"自己的翻牌操作，让记忆失误有补救机会。

- 每关配备3次"时间回溯"机会
- 点击"撤销"按钮，最近翻开的一对卡片会以**时间残影**特效慢慢翻回
- 残影期间卡片半透明，显示"时间倒流中..."提示
- 使用回溯不扣除步数，但会打断 combo
- 回溯动画：卡片边缘产生蓝紫色粒子流，顺时针旋转后翻回背面
- 0次回溯完成解锁"时间掌控者"成就

**技术实现**：
```javascript
// 维护一个操作栈
const actionStack = [];

function flipCard(card) {
    actionStack.push({ 
        type: 'flip', 
        cards: [firstCard, secondCard],
        timestamp: Date.now()
    });
}

function timeRewind() {
    const lastAction = actionStack.pop();
    if (!lastAction) return;
    
    lastAction.cards.forEach(card => {
        card.classList.add('time-ghost');  // 残影样式
        setTimeout(() => {
            card.classList.remove('flipped', 'time-ghost');
        }, 800);
    });
    
    moves = Math.max(0, moves - 1);  // 不扣除步数，但也不退还
}
```

### 5.2 虚拟对手"记忆幽灵"

**核心创意**：一个看不见的AI对手也在"记忆"卡片，和玩家比拼谁先完成配对。

- 幽灵没有实体，通过"幽灵进度条"显示它的进度
- 幽灵的"记忆强度"随关卡递增：初级关卡幽灵每5秒"记住"1对，高级关卡每2秒记住1对
- 幽灵进度条达到100%则玩家失败
- 玩家配对成功会"干扰"幽灵，使其进度倒退5%
- 玩家翻错牌会让幽灵"偷学"，进度前进10%
- 最终结算时显示"你的记忆 vs 幽灵记忆"对比图
- 幽灵会发出低沉的"呼吸"振动反馈（手机振动）

**AI 记忆模型**：
```javascript
const ghostMemory = {
    knownPairs: new Map(),      // 已确定位置的配对
    suspectedPairs: new Map(),  // 猜测的位置
    
    // 幽灵根据玩家翻牌"学习"
    observeCard(cardIndex, cardType) {
        if (this.knownPairs.has(cardType)) return;
        if (this.suspectedPairs.has(cardType)) {
            // 第二次看到，确定配对
            this.knownPairs.set(cardType, [this.suspectedPairs.get(cardType), cardIndex]);
            this.progress += 5;  // 进度+5%
        } else {
            this.suspectedPairs.set(cardType, cardIndex);
        }
    },
    
    // 幽灵"主动"记忆
    autoMemorize() {
        const unknownTypes = [...allTypes].filter(t => !this.knownPairs.has(t));
        if (unknownTypes.length > 0) {
            const randomType = unknownTypes[Math.floor(Math.random() * unknownTypes.length)];
            this.progress += 2;  // 缓慢自动记忆
        }
    }
};
```

### 5.3 卡片进化系统

**核心创意**：频繁配对成功的卡片会"进化"，产生特殊视觉效果和游戏加成。

- 每张卡片有进化等级：Lv1 普通 → Lv2 微光 → Lv3 光芒 → Lv4 传说

- 卡片进化数据永久保存，成为玩家"收藏"的一部分
- 全卡片升到Lv4解锁"进化大师"成就

### 5.4 元叙事模式：记忆碎片

**核心创意**：游戏有一个隐藏剧情，通过配对特定组合解锁剧情碎片。

- 剧情碎片以全屏浮窗呈现，有精美的立绘和文字
- 收集全部16个碎片解锁完整剧情和"真结局"
- 剧情文字随主题变化：暗黑模式下文字是"失去的黑暗记忆"，森林主题是"森林中的相遇"

### 5.5 五行属性克制系统

**核心创意**：卡片不只是图案，还有金木水火土五行属性，属性相生相克影响配对效果。

- 每个 emoji 被赋予一个属性：🐱=木、🐬=水、🐯=火、🐼=土、🦊=金
- 配对规则：
  - 同类卡片配对：正常得分
  - **相生配对**（木→火→土→金→水→木）：虽图案不同但属性相生，计0.5对（需再找真正的配对）
  - **相克配对**（金→木→土→水→火→金）：翻错惩罚加倍，额外倒扣1步
  - **五行俱全**：一局内配对过全部5种属性，额外奖励"五行大师"徽章
- 卡片背面角落显示属性标识（小字），需要仔细看才能发现
- 某些关卡是"属性混乱关"：卡片配对后属性会随机变化

**属性运算**：
```javascript
const attributes = {
    '🐱': 'wood', '🐯': 'fire', '🐼': 'earth', '🦊': 'metal', '🐬': 'water'
};
const generating = { wood: 'fire', fire: 'earth', earth: 'metal', metal: 'water', water: 'wood' };
const overcoming = { metal: 'wood', wood: 'earth', earth: 'water', water: 'fire', fire: 'metal' };

function checkAttributeRelation(type1, type2) {
    const attr1 = attributes[type1];
    const attr2 = attributes[type2];
    if (generating[attr1] === attr2) return 'generating';  // 相生
    if (overcoming[attr1] === attr2) return 'overcoming';  // 相克
    return 'neutral';
}
```

### 5.6 节奏配对模式

**核心创意**：游戏有背景音乐BGM，玩家需要跟随节拍翻牌才能获得完美配对。

- 内置5首不同节奏的BGM（60BPM 到 140BPM）
- 屏幕底部有**节拍指示器**：一个光点随节奏左右移动
- 翻牌时机判定：
  - 完美（±50ms）：配对得分×2，combo+2
  - 良好（±150ms）：正常得分
  - 错过（>±150ms）：配对失败，即使图案相同也会翻回
- BGM 难度分级：Easy 60BPM → Normal 90BPM → Hard 120BPM → Expert 140BPM
- 全完美连击通关解锁"节奏大师"成就
- 玩家自己上传的BGM也能自动分析节拍（Web Audio API 分析 onset）

**节拍检测**：
```javascript
function getBeatsFromAudio(audioBuffer) {
    // 简单的能量阈值节拍检测
    const channelData = audioBuffer.getChannelData(0);
    const blockSize = 512;
    const beats = [];
    let energy = 0, prevEnergy = 0;
    
    for (let i = 0; i < channelData.length; i += blockSize) {
        energy = 0;
        for (let j = 0; j < blockSize; j++) {
            energy += Math.abs(channelData[i + j]);
        }
        if (energy > prevEnergy * 1.3) {  // 能量突增=节拍
            beats.push(i / audioBuffer.sampleRate);
        }
        prevEnergy = energy;
    }
    return beats;
}
```

### 5.7 记忆宫殿模式

**核心创意**：将卡片与虚拟空间位置绑定，训练空间记忆能力（古罗马记忆宫殿法）。

- 棋盘不再是简单的网格，而是一个**房间俯视图**：入口在左下角，窗户在上方，床在右侧，书架在左侧
- 卡片放在房间的不同位置上：门口的鞋子、窗户的花、床上的枕头、书架的书
- 记忆提示不再是"第2行第3列"，而是"窗户旁边的那张卡片"
- 配对成功后会提示："你记住了窗户边的猫咪和门口的猫咪是一对"
- 通关后生成"你的记忆宫殿地图"：显示你对哪个空间位置的记忆最强
- 进阶版：房间布局每3关变化一次（客厅→厨房→卧室→书房→花园）

**空间描述生成**：
```javascript
const roomLayout = {
    name: '客厅',
    zones: [
        { name: '入口', position: [0, 2], landmark: '🚪' },
        { name: '窗边', position: [2, 0], landmark: '🪟' },
        { name: '沙发', position: [1, 1], landmark: '🛋️' },
        { name: '茶几', position: [1, 2], landmark: '☕' },
        { name: '书架', position: [0, 1], landmark: '📚' },
        { name: '电视柜', position: [2, 2], landmark: '📺' }
    ]
};

function getLocationHint(cardIndex) {
    const zone = roomLayout.zones.find(z => z.position[0] * 3 + z.position[1] === cardIndex);
    return zone ? `${zone.landmark}${zone.name}` : '某个角落';
}
```

### 5.8 维度折叠机制

**核心创意**：棋盘可以"折叠"，配对成功后解锁新的维度，卡片总数不变但布局变化。

- 6×6 的棋盘可以横向"对折"成 6×3，被折叠的卡片暂时不可见
- 折叠按钮在棋盘角落，点击后播放折纸动画
- 折叠的意义：
  - 缩小视觉范围，降低认知负荷
  - 折叠时被遮挡的卡片会"记忆模糊"，下次翻开时需要重新确认
- 高级关卡是4维棋盘：有"正面"和"背面"两套卡片，通过"翻转棋盘"切换
- 4维关卡配对规则：同一面的相同图案配对 + 正反两面的相同图案各翻开一次

**折叠动画**：用 CSS 3D 变换实现：
```css
.board-folded .card:nth-child(n+19) {
    transform: rotateY(180deg) translateX(-100%);
    opacity: 0;
    pointer-events: none;
}
.card-inner {
    transition: transform 0.6s cubic-bezier(0.4, 0, 0.2, 1),
                opacity 0.6s ease;
}
```

### 5.9 动态天气系统

**核心创意**：游戏内有随机天气，天气会影响卡片的视觉和效果。

- 天气类型：☀️晴天 / ☁️多云 / 🌧️雨天 / ❄️雪天 / 🌫️雾天 / 🌙夜晚
- 天气每3关随机变化，切换时有全屏天气动画
- 天气效果：
  - ☀️晴天：所有翻牌速度+20%，心情加成
  - 🌧️雨天：卡片玻璃上有雨滴效果，卡片略滑（翻牌延迟+100ms）
  - ❄️雪天：卡片上有积雪，翻牌需要"扫雪"（双击才能翻开）
  - 🌫️雾天：卡片文字模糊，需要鼠标悬停才能看清
  - 🌙夜晚：只有翻开的卡片周围有光圈，未翻开的在黑暗中
- 连续3关遇到坏天气（雨/雪/雾）解锁"风雨无阻"成就

**天气视觉层**：在棋盘上层叠加一个全屏 canvas 层绘制粒子：
```javascript
function drawWeather(weather) {
    if (weather === 'rain') {
        for (let i = 0; i < 100; i++) {
            ctx.fillStyle = 'rgba(174, 194, 224, 0.5)';
            ctx.fillRect(raindrops[i].x, raindrops[i].y, 2, 10);
            raindrops[i].y += 8;
            if (raindrops[i].y > canvas.height) raindrops[i].y = -10;
        }
    }
}
```

### 5.10 收藏家系统

**核心创意**：除了正常的卡片图案，还有极低概率掉落"稀有卡面"，可收集、合成、展示。

- 稀有卡面分级：N普通 → R稀有 → SR超稀有 → SSR史诗 → UR传说
- 掉落概率：R 5% / SR 1% / SSR 0.1% / UR 0.01%
- 稀有卡面有特殊动态效果：
  - R：卡片边框颜色变化
  - SR：卡片有粒子拖尾
  - SSR：配对时播放专属动画
  - UR：有独立的背景故事和成就
- 收集系统：
  - 重复的稀有卡可以"分解"为碎片
  - 100个碎片可以"合成"指定的SSR卡
  - 收集册可以展示获得的稀有卡
  - 每月限定卡：每月更新一张限定UR卡，过后不再掉落
- 全图鉴收集解锁"传说收藏家"称号，游戏标题旁显示金色皇冠

**抽卡机制**：

```javascript
function gachaRoll() {

    if (rand < 0.01)   return { rarity: 'SR', card: getRandomSRCard() };
    if (rand < 0.05)   return { rarity: 'R', card: getRandomRCard() };
    return { rarity: 'N', card: getRandomNormalCard() };
```

### 5.11 冥想/禅意模式

**核心创意**：无压力的纯记忆训练，配合呼吸引导动画，适合放松和专注力训练。

- 无步数限制、无时间限制、无炸弹、无评分
- 背景音是白噪音或轻音乐（雨声、森林、海浪）
- **呼吸引导**：屏幕角落有呼吸圈，吸气时扩大4秒，屏息2秒，呼气时缩小4秒
- 提示文字改为正念引导："感受你的呼吸，注意卡片的位置"、"不必着急，记忆自然会浮现"
- 每次配对成功有柔和的"叮"声和淡淡的涟漪效果
- 完成后显示"你专注了 X 分钟"，并可以记录心情（1-5分）
- 累计冥想1小时解锁"心如止水"成就
- 与手机健康数据集成（如果可用），记录专注时段

### 5.12 突触强化机制

**核心创意**：模拟大脑神经突触的强化——两张卡片翻牌间隔越短，"记忆突触"越强，下次翻开时提供记忆提示。

- 记录每对卡片的翻牌历史：时间戳、间隔、是否配对成功
- **突触强度公式**：`strength = exp(-α * timeInterval) * (success ? 1.5 : 1.0)`
- 强度显示：卡片角落显示突触连接强度的光点，越强越亮
- 高强度效果：
  - 强度 > 0.8：鼠标悬停时显示"你可能记得这张卡片"的淡色提示
  - 强度 > 0.95：自动显示半透明的卡片图案（"肌肉记忆"效果）
- 每局结束显示"突触连接热图"：哪些位置的记忆最深刻
- 长期效果：累计突触最强的5对卡片会永久"记住"，下一次遇到相同图案时自动标记

**突触可视化**：
```javascript
function getSynapseStrength(card1, card2) {
    const history = getFlipHistory(card1, card2);
    let strength = 0;
    history.forEach(event => {
        // 艾宾浩斯遗忘曲线模拟
        const decay = Math.exp(-0.1 * event.daysAgo);
        const intervalEffect = Math.exp(-0.001 * event.interval);
        strength += decay * intervalEffect * (event.success ? 1.5 : 1.0);
    });
    return Math.min(1, strength);
}
```

## 九、创新玩法落地优先级建议

### 9.1 第一梯队（投入产出比最高，优先做）

| 玩法 | 为什么优先 |
|------|-----------|
| **冥想/禅意模式** | 工作量仅2.5人天，几乎不需要改动核心逻辑，独立模块。差异化明显——市面上很少有记忆游戏做"禅意"定位，能吸引特定用户群 |
| **时间回溯机制** | 3人天，技术实现简单（操作栈），但给玩家的"安全感"提升巨大。翻错了可以撤销，显著降低挫败感，提升留存 |
| **五行属性克制** | 3人天，只需要给 emoji 打属性标签 + 简单的关系判断。在不改变核心玩法的前提下大幅增加策略深度 |
| **卡片进化系统** | 4人天，跨关卡的成长感。一旦上线，玩家会为了升级卡片而反复游戏，大幅提升日活和时长 |

### 9.2 第二梯队（有特色但工作量中等）

| 玩法 | 适合时机 |
|------|---------|
| **动态天气系统** | 4人天，视觉效果震撼，适合作为大版本更新的"门面"功能 |
| **维度折叠机制** | 3.5人天，玩法创新，可以作为"独家特色"宣传 |
| **元叙事剧情** | 6人天，工作量大但长线价值高——有剧情的游戏玩家粘性会明显更高。建议等核心玩法稳定后再投入 |
| **收藏家系统** | 5人天，抽卡机制成瘾性强，但需要美术资源支持（稀有卡设计），适合有一定用户基础后做 |

### 9.3 第三梯队（高投入高风险，最后做）

| 玩法 | 风险点 |
|------|-------|
| **虚拟对手"记忆幽灵"** | 5人天，AI 难度调优很关键——太简单玩家觉得无聊，太难玩家被劝退。需要大量测试 |
| **节奏配对模式** | 4人天，节拍检测的准确性是关键，Web Audio API 在不同浏览器表现有差异 |
| **记忆宫殿模式** | 5人天，需要设计大量房间布局和场景文案，且空间绑定对部分玩家反而增加认知负担 |
| **突触强化机制** | 5.5人天，技术复杂度最高，需要大量用户数据来验证模型是否真的"符合人类记忆规律" |

### 9.4 推荐落地路径

```
第1个月：冥想模式 + 时间回溯  →  验证玩家反馈
第2个月：五行属性 + 卡片进化  →  增加策略深度和留存
第3个月：动态天气 + 维度折叠  →  视觉和玩法的大版本更新
第4-6个月：元叙事 + 收藏家    →  长线粘性系统
第6个月后：幽灵/节奏/宫殿/突触 →  高风险创新玩法按需投入
```
