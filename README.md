## 📖 项目简介

**游戏盒子 (Game Box)** 是一个纯前端实现的休闲小游戏合集平台。无需下载安装，无需后端服务，打开浏览器即可游玩。平台精选了多款经典休闲游戏，涵盖益智、策略、街机等多种类型。

- **🌐 官方网站**：[game-box.magipoet.com](https://github.com/Magipoet/game_box)
- **📱 兼容性**：支持 PC、平板、手机全平台
- **🎯 目标**：打造轻量、优质、可即点即玩的网页游戏集合

---

## 🏗️ 技术架构

本项目采用**原生 HTML + CSS + JavaScript** 开发，无需任何框架依赖，保持代码轻量高效。

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 结构层 | **HTML5** | 语义化标签，无障碍支持 |
| 表现层 | **CSS3** | Flexbox/Grid 布局，响应式设计，CSS 动画 |
| 逻辑层 | **Vanilla JavaScript (ES6+)** | 模块化设计，DOM 操作，Canvas 渲染 |

### 架构特点

1. **零依赖**：不依赖任何前端框架或构建工具
2. **模块化**：每个游戏独立封装，代码互不干扰
3. **可扩展**：游戏接入遵循统一规范，新增游戏简单便捷
4. **渐进增强**：核心玩法在低版本浏览器也能正常运行

## 🎯 游戏列表

### 🎴 翻牌配对 (Memory Match)

**位置**：`games/memory-match/`

**游戏介绍**：
经典的记忆力训练游戏。点击卡片翻开图案，找出所有配对的卡片即可过关。游戏考验玩家的记忆能力和专注力。

**基本玩法**：
1. 点击任意卡片翻开，记住图案位置
2. 每次可以翻开两张卡片
3. 如果两张卡片图案相同，则配对成功，保持翻开状态
4. 如果图案不同，卡片会自动翻回背面
5. 找出所有配对的卡片即可获胜

**游戏特色**：
- 📊 三档难度可选（简单4×3、中等4×4、困难6×4）
- ⏱️ 计时器记录通关时间
- 🔢 翻牌次数统计
- 🎯 最佳成绩记录（localStorage 持久化）
- ✨ 精美的翻转动画效果

**操作方式**：鼠标点击 / 触屏点击

### 🐍 贪吃蛇 (Snake)

**位置**：`games/snake/`

**游戏介绍**：
经典街机游戏的现代重制版。控制蛇吃掉食物，不断成长，挑战最高分。支持多种主题、成就系统和双人对战模式。

**基本玩法**：
1. 使用方向键（↑↓←→）或 WASD 控制蛇的移动方向
2. 蛇头碰到食物（彩色方块）后会变长，得分增加
3. 蛇头撞到墙壁或自身身体，游戏结束
4. 按空格键可暂停/继续游戏

**游戏特色**：
- 🏆 最高分记录
- 🎨 多种主题皮肤（经典、霓虹、像素、森林、糖果）
- 🏅 成就系统（首次得分、蛇长达到10、无失误达人等）
- 👥 双人对战模式（玩家1：WASD，玩家2：方向键）
- 📱 支持触屏滑动操作

**文件结构**：
- `js/app.js` — 应用入口、UI 控制
- `js/game.js` — 游戏核心逻辑、蛇和食物
- `js/theme.js` — 主题切换
- `js/achievements.js` — 成就系统

### ❌⭕ 动态井字棋 (X & O)

**位置**：`games/x-and-o/`

**游戏介绍**：
传统井字棋的创新玩法。棋盘上最多只能存在3个棋子，放下第4个棋子时，最早的棋子会消失，带来全新的策略深度。

**基本玩法**：
1. 两名玩家轮流在3×3棋盘上落子（X先手）
2. 每位玩家的棋盘上最多保留3个棋子
3. 放下第4个棋子时，该玩家最早的棋子会消失
4. 率先将三个棋子连成一线（横、竖、斜）的玩家获胜

**游戏模式**：
- **常规模式**：标准动态井字棋，支持撤回和重新开始
- **趣味模式**：每位玩家拥有三个特殊技能：
  - ↶ **撤回**（×1）：撤销自己的上一步操作
  - 🔒 **固定**（×1）：选择一个空格子，对方下一次落子后解除锁定
  - ⏳ **保留**（×1）：下一步落子的棋子将保留5个回合（普通仅3回合）

**游戏特色**：
- 🤖 支持双人对战和AI对战（3级难度）
- 🎨 多种主题（明亮、深色、午夜、糖果、橘子海、日落、森林）
- 💾 设置记忆功能（记住上次访问的设置页面）
- 🔢 棋子右下角显示存活回合数
- ⏳ 保留棋子显示沙漏图标，🔒 固定格子显示锁图标

**文件结构**：
- `game.js` — 游戏核心逻辑（状态管理、胜负判断、技能系统）
- `board.js` — 棋盘渲染、UI 交互、事件绑定
- `style.css` — 样式、主题、响应式布局

### 2️⃣0️⃣4️⃣8️⃣ 2048消消乐

**位置**：`games/2048/`

**游戏介绍**：
经典数字合成游戏。通过滑动合并相同数字，逐步合成更大的数字，目标是合成 2048！

**基本玩法**：
1. 使用方向键（↑↓←→）或滑动操作移动所有方块
2. 相同数字的方块相撞时会合并成它们的和（如 2+2=4，4+4=8）
3. 每次移动后，会随机在空白处生成一个新的 2 或 4
4. 当棋盘填满且无法合并时，游戏结束
5. 合成 2048 即获胜，可继续挑战更高分

**游戏特色**：
- 📊 实时分数显示 + 最高分记录
- ↶ 撤回功能（支持撤销上一步）
- 🎯 目标达成提示
- ✨ 流畅的滑入和合并动画
- 📱 支持触屏滑动操作

## 🚀 快速开始

### 方式一：直接访问

访问 [GitHub Pages](https://magipoet.github.io/game_box/) 或任意静态托管的站点。

### 方式二：本地运行

```bash
# 克隆项目
git clone https://github.com/Magipoet/game_box.git

# 进入项目目录
cd game_box

# 启动本地服务器（任选其一）
python3 -m http.server 8080
# 或
npx serve .
# 或
php -S localhost:8080
```

然后在浏览器中打开 `http://localhost:8080` 即可。

### 方式三：直接打开

直接双击 `index.html` 在浏览器中打开（部分浏览器可能会限制 localStorage 功能）。
